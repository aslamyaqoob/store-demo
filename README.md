# Rang Bazaar (demo store)

A demo storefront for a Karachi online store, a single static page with no build step.

- Shop with categories, search, sorting and quick view
- Cart, free-delivery progress and checkout (cash on delivery, JazzCash/Easypaisa)
- PKR / AED / USD currency switcher (charged in rupees)
- Order confirmation by WhatsApp
- Demo admin at `/#admin`: products, stock, orders, CSV export, best and slow sellers, settings

Products, prices and the store name are samples. The demo admin saves to the visitor's own browser only.

Deploy: import this repository in Vercel (framework preset "Other"); there is nothing to build.
